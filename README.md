# Jaydeep & Dhara – Wedding Website

A free, responsive wedding invitation website built with plain HTML, CSS and JavaScript.

## Included
- Deepotsav-inspired animated opening scene (CSS temple silhouette, stars and glowing diyas)
- English / Gujarati text toggle
- Wedding countdown to 11 December 2026
- All eight previously shared functions
- Family names
- Photo gallery placeholders
- Google Maps link to Vadodara (replace with the final venue pin)
- RSVP form with email fallback and optional Google Forms link
- Print stylesheet: use **Print invitation / Save PDF** and choose **Save as PDF**

## 1. Preview on your computer
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Internet is needed for the Google Fonts. The rest of the site runs locally.

## 2. Personalise before publishing
Open `index.html` in a text editor and replace:
- Each `Time & venue to be announced` with the final time and venue.
- The generic Vadodara Google Maps URL with your exact venue's Google Maps share link.
- Gallery placeholders with your own photographs (instructions below).

Open `script.js` and edit the `CONFIG` object:
- `weddingStart`: set the exact local start date/time if you want a more precise countdown.
- `googleFormUrl`: paste the public link to your Google Form.

### RSVP setup (recommended)
The included form provides an email fallback. For automatic online collection:
1. Create a Google Form with fields: Name, Number of guests, Attendance, Message.
2. Copy its responder link.
3. Paste that link into `googleFormUrl` in `script.js`.
4. The website's RSVP button opens the Google Form. (The current simple integration opens the form; it does not silently submit its fields into Google Forms.)

For a seamless embedded RSVP, you can replace the RSVP section with Google's **Send > Embed HTML** iframe code. Use the exact embed URL generated by Google Forms.

## 3. Add your photographs
1. Copy image files into `assets/`, e.g. `couple-1.jpg`, `couple-2.jpg`, `family.jpg`, `moments.jpg`.
2. In `index.html`, find `<div class="gallery-grid">`.
3. Replace each `.gallery-placeholder` block with an image, for example:

```html
<div class="gallery-photo"><img src="assets/couple-1.jpg" alt="Jaydeep and Dhara"></div>
```

4. Add this CSS to the end of `style.css`:

```css
.gallery-photo { overflow:hidden; min-height:180px; border:1px solid #a9854c; }
.gallery-photo img { width:100%; height:100%; object-fit:cover; display:block; }
```

Use compressed images (ideally under 500 KB each) so the site loads quickly on phones.

## 4. Add background music
1. Add an MP3 file you have permission to use to `assets/`.
2. Name it `wedding-music.mp3`.
3. The music button plays/pauses it. Browsers require a user tap before audio can play.

## 5. Publish free with GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Create a **Public** repository named `jaydeep-dhara-wedding`.
3. Upload `index.html`, `style.css`, `script.js`, `README.md` and the `assets` folder.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then Save.
7. Wait for deployment. Your free website address will be:
   `https://YOUR-GITHUB-USERNAME.github.io/jaydeep-dhara-wedding/`

If the URL does not appear immediately, refresh Settings → Pages after a minute or two.

## 6. Save invitation as PDF
Open the published website in Chrome:
1. Tap **Print invitation / Save PDF** at the bottom.
2. Choose **Save as PDF**.
3. Set paper size to A4 and enable background graphics if you want the colours.
4. Save.

The print stylesheet creates a simplified printable invitation. For a full-page graphic invitation, make a separate design in Canva.
